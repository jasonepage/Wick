# Getting help

## If you play Wick

- **Questions about the game, coins or the App Store:** email
  support@guesswick.com or see the
  [support page](https://guesswick.com/marketing/support.html).
- **Something is broken:** a
  [bug report](https://github.com/jasonepage/Wick/issues/new/choose) is the
  fastest way to get it fixed. Please give the puzzle number, not the answer.

## If you build with the code

- **Setting up, running the tests, or sending a change:** start with
  [CONTRIBUTING.md](CONTRIBUTING.md).
- **How the parts fit together:** the [README](README.md) covers scoring, the
  server routes and the folder layout. `wick-api/README.md` and
  `wick-web/README.md` go deeper on each part.
- **A question the docs do not answer:** open an issue and say what you were
  trying to do.

## Security problems

Please do not post them in a public issue. See [SECURITY.md](SECURITY.md).
